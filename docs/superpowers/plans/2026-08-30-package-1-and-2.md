# Package 1 and Package 2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan. Use one writer in this checkout and do not begin Package 3.

**Goal:** Publish a privacy-neutral Apache-2.0 source repository, then complete the local Package 1 domain foundation and Package 2 read/propose vertical slice without changing the unresolved Package 0 hosted verdict.

**Architecture:** Keep the generated Vinext/Next.js/Cloudflare stack. Put all authorization and state transitions in server-only domain services backed by prepared D1 statements; route handlers and top-level imperative WebMCP tools are thin adapters over those services. Resolve the anonymous workspace exclusively from a signed host-only cookie, keep retrieval pure, and make proposal creation an atomic guard-to-finalizer batch that cannot alter the implemented revision.

**Tech Stack:** TypeScript 5.9, React 19, Next.js/Vinext, Cloudflare Workers and D1, Drizzle schema declarations, Zod strict runtime schemas, Node test runner, Cloudflare Vitest pool, Playwright CLI, ESLint, npm audit.

**Spec:** `docs/delivery/CODEX_IMPLEMENTATION_PLAN.md` Packages 1 and 2, with Revision 2 authority in `START_HERE.md` mandatory order.

## Global constraints

- Preserve anonymous-only identity. Package 0 did not prove hosted identity-header anti-spoofing, so no Package 1 or 2 production path may import `app/chatgpt-auth.ts`.
- Preserve Package 0 as `INCONCLUSIVE`; local Package 1/2 evidence may not relabel the hosted ChatGPT/WebMCP requirement.
- Public Git publication is authorized; Sites deployment, access changes, hosted D1, identity probes, Devpost, Package 3, secrets, and force pushes are forbidden.
- TDD is mandatory: observe each new regression fail for the intended reason before implementing it.
- Every write uses prepared SQL, a server-resolved workspace, exact row-count semantics, idempotency where declared, and safe public errors.
- Retrieval can establish bounded evidence support; it never supplies approval or application authority.
