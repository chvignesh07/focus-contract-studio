# Code of Conduct

## Our commitment

We want Focus Contract Studio to be a respectful, accessible place to build and
review software. Participants are expected to make collaboration safe for
people of every background, identity, experience level, and communication or
access need.

## Expected behavior

- Be specific, kind, and evidence-led in reviews.
- Critique the work, not the person.
- Respect stated names, pronouns, boundaries, and accessibility needs.
- Welcome questions and explain decisions without gatekeeping.
- Protect private information and report security concerns privately.
- Accept correction, repair harm, and make space for others to contribute.

## Unacceptable behavior

Harassment, threats, discrimination, sexualized attention, deliberate
misgendering, stalking, doxxing, intimidation, sustained disruption, or sharing
someone's private information without permission are not tolerated.

## Scope and reporting

This code applies in repository issues, pull requests, reviews, discussions,
project events, and public spaces where someone represents the project.

Report conduct concerns to the repository owner through the contact method on
the [maintainer's GitHub profile](https://github.com/chvignesh07). Do not publish
private evidence in an issue. Security-specific reports follow
[SECURITY.md](SECURITY.md).

Reports will be considered in context and handled as privately as practical.
Project maintainers may remove content, request a correction, issue a warning,
temporarily restrict participation, or permanently remove a participant when
needed to protect the community. Retaliation against a reporter is prohibited.

## Responsibility

Maintainers are responsible for clarifying and enforcing these expectations
consistently. Anyone involved in a report must disclose conflicts of interest
and step back when impartial review is not possible.
